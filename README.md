# TaskChain 时间推进插件

让 AI 角色在说"我去泡杯咖啡"之后，真的等一会儿再端着咖啡回来——而不是秒回"给，您的咖啡！"

## 为什么需要这个

传统 chatbot 的问题：AI 说"我去泡杯咖啡"，然后**立刻**说"咖啡好了，趁热喝"。用户感知不到时间流逝，对话没有"进行中"的状态，沉浸感瞬间消失。

这个插件给 AI 角色赋予了**真实的时间感**：
- AI 说去做什么 → 背后真的有一个计时器在跑
- 中途会找话题互动 → 不是在沉默中等
- 到点才回来告诉结果 → 时间感真实

## 架构设计

```
用户说"帮我泡杯咖啡"
    │
    ▼
AI 调用 chain_task create ──→ 创建任务链 ──→ 按人设自然回应说"好嘞！"
    │
    ├─→ [30~60s 后] 中途互动 ──→ AI 主动问："博士加糖还是加奶？"
    │       │
    │       ├─→ 用户回复 → 自然对话继续
    │       └─→ 用户没回 → 50% 概率发个"😸"
    │
    └─→ [N分钟后] 任务完成 ──→ AI："咖啡好啦，加了两块糖～"
                              （结合了之前和用户的对话）
```

### 核心组件

| 组件 | 说明 |
|------|------|
| `chain_task` LLM 工具 | AI 通过 create/list/cancel/advance 管理任务 |
| 调度器 `_scheduler_loop` | 后台每 10s 检查，到点触发回调 |
| `on_llm_request` 钩子 | 每次 LLM 请求前注入任务状态 + 工具使用规则 |
| 中途互动阶段 | 长任务自动插入检查点，AI 主动找话题 |
| 完成监听 | 最后 10s 窗口期，用户消息优先，避免"已完成+用户还在聊"的尴尬 |
| Followup 检查 | interact 后 45~90s 检查用户是否回复，没回就简短喵一下 |

### 工具使用规则注入

插件通过 `on_llm_request` 钩子，在每次 LLM 请求时自动向 system_prompt 注入以下规则：

> 当你准备承诺一个需要等待的动作时，必须先调用 chain_task 创建任务，再用角色语气自然回应。

这让 AI 知道：
- 哪些场景必须调用工具（泡茶、拿东西、去厨房等）
- 什么时候不需要（纯粹闲聊、假设）
- 当前有哪些活跃任务，各自处于什么状态

### 完成监听机制

主任务最后 10 秒进入"监听窗口"：如果用户在这期间发了消息，系统立即告知 AI 任务已完成，AI 直接给出结果，不需要等后台回调。这避免了"用户问、AI回调说完成了、用户又发消息"的混乱时序。

### 会话隔离

任务与对话绑定（`conversation_id`），重置对话或新建对话时自动取消旧链。同一用户不同对话互不干扰。

## 典型场景

### 泡咖啡（短任务）
```
博士: 帮我泡杯咖啡
佩佩: 好嘞！[调用 chain_task create(name="泡咖啡", duration=5)]
佩佩: 我这就去准备～
──── 约 40s 后 ────
佩佩: 博士，加糖还是加奶呀？☕
博士: 加糖，两块
佩佩: 两块够不够，还是要三块甜到心坎里？
博士: 够啦
──── 约 5min 后 ────
佩佩: 咖啡好啦！给你加了两块糖，趁热喝～☕
```

### 学习（长时间任务）
```
博士: 我去看会书
佩佩: 好呀，我不吵你～
[调用 chain_task create(name="学习", duration=30)]
──── 约 45s 后 ────
佩佩: （悄悄写笔记，偶尔抬头看博士）这题好难啊！😫

[博士继续学习，没有回复]
──── 约 60s 后 ────
佩佩: 喵~ （轻轻翻了一页书）

[又过了大约 25 分钟]
──── 30min 后 ────
佩佩: 博士，这一章太精彩了！那个转折你看到了吗？
```

### 拿东西（微任务）
```
博士: 帮我从书房拿个笔记本
佩佩: 好嘞！[调用 chain_task create(name="找笔记本", duration=3)]
佩佩: 我去翻翻，记得在左边抽屉...
──── 约 40s 后 ────
佩佩: 红色封面的还是蓝色的？我找到了两本！
博士: 红的
──── 约 3min 后 ────
佩佩: 找到啦！给你～📒
```

## 安装

### Docker 安装
```bash
# 假设 AstrBot 数据目录为 /opt/astrbot/data
cp -r astrbot-plugin-taskchain /opt/astrbot/data/plugins/astrbot_plugin_taskchain_tool
docker restart astrbot
```

### 本地安装
```bash
cp -r astrbot-plugin-taskchain /path/to/AstrBot/data/plugins/astrbot_plugin_taskchain_tool
astrbot restart
```

### 返回结果
```
[任务已安排(id=xxxx)] 预计14:32完成。
```

### 查看状态
```
actions=list → 返回所有活跃任务的剩余时间
```

### 取消任务
```
action=cancel, chain_id=xxxx → 取消指定任务
```

## 为什么提升沉浸感

| 没有插件时 | 有插件时 |
|-----------|---------|
| "我去泡咖啡" → 秒回"咖啡好了" | "我去泡咖啡" → 等几分钟 → "咖啡好啦" |
| 中间完全沉默 | 中途会问"加糖还是加奶" |
| 不会聊天 | 等待期间自然互动 |
| 时间感不存在 | 角色做的事有真实的时间长度 |
| 对话像流水账 | 对话有起伏、有等待、有回报 |

核心：把"AI 说了就等于做了"变成"AI 说了 → 正在做 → 做完了"，让角色扮演有了**时间维度**。
